DURANTE COMPETENCIA (EN LA SEDE DEL EVENTO)
════════════════════════════════════════════════════════════════════════════════

Llegada (2-3 horas antes de la primera partida):
  ☐ [ ] Desempacar todos los robots y controles
  ☐ [ ] Verificación visual: sin daños por transporte
  ☐ [ ] Conectar USB a cada robot y control, verificar serial output
         Esperado: "Iniciando robot ESP-NOW, par X"
  
  ☐ [ ] Prueba de rango en la sede
         Anotar WIFI_CHANNEL óptimo (si hay interferencia, cambiar)
  
  ☐ [ ] Prueba final de failsafe
         Apagar control, verificar freno < 300ms
  
  ☐ [ ] Cargar batería del control (si está baja)

Antes de cada partida:
  ☐ [ ] Verificar que baterías del robot están cargadas
  ☐ [ ] Encender robot y control, esperar 3 segundos
  ☐ [ ] Serial del robot debe mostrar: "Enlace valido: control habilitado"
  ☐ [ ] LED del robot debe estar HIGH (verde/azul)
  ☐ [ ] Mover joystick para verificar responsividad
  ☐ [ ] LISTO PARA JUGAR

Después de cada partida:
  ☐ [ ] Apagar robot y control
  ☐ [ ] Si batería del robot está baja (< 6.9V): CAMBIAR INMEDIATAMENTE
  ☐ [ ] Si quedan más de 15 minutos antes de la siguiente partida: recargar control
  ☐ [ ] Inspeccionar daños menores (cables flojos, soldaduras frías, etc.)

Si falla algo durante competencia:
  ☐ [ ] Control no responde:
         → Cambiar a control respaldo (requiere 5 min de reprogramación con PAIR_ID)
         → O cambiar robot a control de otro par (no permitido por reglamento, probablemente)
  
  ☐ [ ] Robot no enciende:
         → Cambiar batería 2S (llevar 2 juegos)
         → Si problema persiste: usar robot de respaldo (reprogramar PAIR_ID)
  
  ☐ [ ] Frenado lento (failsafe no activa rápido):
         → Verificar capacitor electrolítico (no inflado, no frío)
         → Verificar conexión de GND
  
  ☐ [ ] Latencia alta (lag):
         → Cambiar WIFI_CHANNEL (si permite reglamento)
         → Verificar que team_config.h tiene claves correctas
  
  ☐ [ ] Interferencia de otro equipo:
         → Coordinar cambio de WIFI_CHANNEL con otros equipos
         → Alejar equipos si es posible
